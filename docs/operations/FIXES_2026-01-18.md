## Issues Fixed

### 1. Missing i18n Translations ✅

**Problem**: Browser console showed missing translation keys for rental object categories:
- `sdk.rentalObject.category.ARRANGEMENT`
- `sdk.rentalObject.category.MØTEROM`
- `sdk.rentalObject.category.UTSTYR`

**Root Cause**: Database had different category keys than what i18n translations covered. The seed data used simplified keys (ARRANGEMENT, MØTEROM, UTSTYR) but translations only existed for the full keys (OPPLEVELSER_OG_ARRANGEMENT, etc.).

**Solution**: Added missing translations to both Norwegian and English locale files.

**Files Modified**:
- `packages/i18n/src/locales/nb.ts` - Added 3 translations
- `packages/i18n/src/locales/en.ts` - Added 3 translations

**Translations Added**:

### 2. Images Not Showing ✅

**Problem**: Rental object images were not displaying. Image URLs like `/seed-images/lokaler-og-baner/soccer-field.png` returned 404 errors.

**Root Cause**: The API had static file serving configured for `/storage/` prefix, but rental object image URLs used `/seed-images/` prefix. The images exist in `storage/seed-images/` directory but were not accessible via the `/seed-images/` route.

**Solution**: Added a second static file route in Fastify to serve images from `storage/seed-images/` at the `/seed-images/` prefix.

**File Modified**:
- `apps/api/src/adapters/fastify.adapter.ts`

**Code Added**:
```typescript
// Register seed-images static file serving
// Serves files from apps/api/storage/seed-images/ at /seed-images route
const seedImagesDir = path.join(process.cwd(), 'storage', 'seed-images');
await app.register(fastifyStatic, {
  root: seedImagesDir,
  prefix: '/seed-images/',
  decorateReply: false,
});
```
