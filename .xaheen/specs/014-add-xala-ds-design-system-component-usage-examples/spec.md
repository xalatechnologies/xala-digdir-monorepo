# Add @xala/ds design system component usage examples

## Overview

The @xala/ds package contains 80+ components across primitives, composed, blocks, and shells but lacks a component catalog with usage examples. Developers must read source code to understand props, variants, and composition patterns.

## Rationale

The design system facade (@xala/ds) is the ONLY allowed way to import UI components. Without usage examples, developers spend time reverse-engineering component APIs. The packages/ds-registry exists but doesn't provide searchable component documentation.
