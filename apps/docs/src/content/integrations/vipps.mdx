# Vipps Integration

The Xala/Digilist platform integrates with Vipps MobilePay for seamless payment processing.
This integration enables Norwegian citizens to pay for bookings using their preferred mobile
payment method, providing a familiar and secure checkout experience.

## Integration Overview

<Callout variant="info" title="Norwegian Payment Standard">
Vipps is the preferred payment method in Norway, used by over 4 million Norwegians. Integration
with Vipps provides the most familiar checkout experience for municipal services.

## SDK Usage

<CodeBlock
  title="Initiating Vipps Payment"
  language="tsx"
  code={`import { useVippsPayment } from '@digilist/client-sdk/hooks';

function BookingCheckout({ booking }) {
  const { initiatePayment, isLoading, error } = useVippsPayment();

  const handlePayment = async () => {
    const result = await initiatePayment({
      bookingId: booking.id,
      amount: booking.totalPrice,
      description: \`Booking: \${booking.listing.name}\`,
      phoneNumber: booking.user.phone, // Optional for express checkout
    });

    if (result.redirectUrl) {
      window.location.href = result.redirectUrl;
    }
  };

  return (
    <Button onClick={handlePayment} loading={isLoading}>
      Pay with Vipps
    </Button>
  );
}`}
  showLineNumbers
/>

<CodeBlock
  title="Handling Payment Callbacks"
  language="tsx"
  code={`import { useVippsCallback } from '@digilist/client-sdk/hooks';

function PaymentCompletePage() {
  const { status, booking, error, isLoading } = useVippsCallback();

  if (isLoading) {
    return <Spinner label="Verifying payment..." />;
  }

  if (error) {
    return <PaymentErrorView error={error} />;
  }

  if (status === 'AUTHORIZED' || status === 'CAPTURED') {
    return <BookingConfirmation booking={booking} />;
  }

  if (status === 'CANCELLED') {
    return <PaymentCancelledView bookingId={booking.id} />;
  }

  return <PaymentPendingView />;
}`}
  showLineNumbers
/>

## Webhook Events

<CodeBlock
  title="Vipps Webhook Events"
  language="typescript"
  code={`// Webhook events received from Vipps
type VippsWebhookEvent =
  | 'AUTHORIZED'    // Payment authorized, ready to capture
  | 'CAPTURED'      // Payment captured successfully
  | 'CANCELLED'     // Payment cancelled by user
  | 'REFUNDED'      // Refund processed
  | 'EXPIRED'       // Payment session expired
  | 'FAILED';       // Payment failed

// Webhook handler (server-side)
app.post('/webhooks/vipps', async (req, res) => {
  const { event, orderId, transactionInfo } = req.body;

  // Verify webhook signature
  const isValid = vippsService.verifyWebhook(req);
  if (!isValid) {
    return res.status(401).json({ error: 'Invalid signature' });
  }

  // Process webhook event
  switch (event) {
    case 'AUTHORIZED':
      await capturePayment(orderId);
      break;
    case 'CAPTURED':
      await confirmBooking(orderId);
      break;
    case 'CANCELLED':
      await cancelBooking(orderId);
      break;
    case 'REFUNDED':
      await processRefundComplete(orderId);
      break;
  }

  res.status(200).json({ received: true });
});`}
  showLineNumbers
/>

## Common Errors

<Callout variant="danger" title="vipps/authentication-failed">
**Error Code:** `vipps/authentication-failed`

**Cause:** Invalid Vipps API credentials or expired access token.

**Solution:** Verify VIPPS_CLIENT_ID and VIPPS_CLIENT_SECRET in environment variables. Regenerate credentials in Vipps Merchant Portal if needed.
</Callout>

<Callout variant="danger" title="vipps/payment-cancelled">
**Error Code:** `vipps/payment-cancelled`

**Cause:** User cancelled the payment in the Vipps app.

**Solution:** No action needed. User can retry payment from the booking page.
</Callout>

<Callout variant="warning" title="vipps/capture-failed">
**Error Code:** `vipps/capture-failed`

**Cause:** Payment authorization has expired or insufficient funds at capture time.

**Solution:** Contact user to retry payment. Check if the authorization window (7 days) has expired.
</Callout>

<Callout variant="danger" title="vipps/refund-failed">
**Error Code:** `vipps/refund-failed`

**Cause:** Refund amount exceeds captured amount or refund window has passed.

**Solution:** Verify refund amount. For older transactions, process refund manually through Vipps Merchant Portal.
</Callout>

<Callout variant="warning" title="vipps/webhook-verification-failed">
**Error Code:** `vipps/webhook-verification-failed`

**Cause:** Webhook signature does not match. Possible tampering or misconfiguration.

**Solution:** Verify VIPPS_WEBHOOK_SECRET matches the value in Vipps Developer Portal.
</Callout>
