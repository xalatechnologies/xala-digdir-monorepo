# Demo Seeding

The Xala/Digilist platform provides comprehensive demo seeding capabilities to quickly
populate development and staging environments with realistic test data. This enables
evaluators, developers, and testers to explore the full functionality of the platform.

## Why Use Demo Seeds?

<Callout variant="info" title="For Evaluators">
Demo seeding creates a fully functional environment with pre-configured users, organizations,
listings, bookings, and all related data. This allows you to immediately explore the platform
without manually creating test data.

## Troubleshooting

<Callout variant="danger" title="seed/connection-failed">
**Error Code:** `seed/connection-failed`

**Cause:** Cannot connect to the database. The DATABASE_URL may be incorrect or the database server is not running.

**Solution:** Verify your `.env` file contains the correct DATABASE_URL and that your database server is running.
</Callout>

<Callout variant="danger" title="seed/migration-required">
**Error Code:** `seed/migration-required`

**Cause:** Database schema is out of date. Migrations need to be applied before seeding.

**Solution:** Run `pnpm db:migrate` before attempting to seed.
</Callout>

<Callout variant="warning" title="seed/duplicate-data">
**Error Code:** `seed/duplicate-data`

**Cause:** Seed data already exists. Running seeds multiple times can cause conflicts.

**Solution:** Use `pnpm seed:reset` to clear existing data before reseeding, or use `--force` flag to overwrite.
</Callout>

<Callout variant="danger" title="seed/permission-denied">
**Error Code:** `seed/permission-denied`

**Cause:** Current environment does not allow seeding. Production environments block seed commands by default.

**Solution:** Seeding is not allowed in production. Use staging or development environment.
</Callout>

## SDK Usage for Custom Seeds

<CodeBlock
  title="Creating Custom Seeds"
  language="typescript"
  code={`import { seedService } from '@digilist/client-sdk';

async function customSeed() {
  // Create organization
  const org = await seedService.createOrganization({
    name: 'Custom Sports Club',
    type: 'SPORTS',
  });

  // Create listing under organization
  const listing = await seedService.createListing({
    organizationId: org.id,
    name: 'Tennis Court 1',
    type: 'OUTDOOR',
    capacity: 4,
  });

  // Create bookings
  await seedService.createBookings({
    listingId: listing.id,
    count: 10,
    dateRange: {
      start: new Date(),
      end: new Date(Date.now() + 30 * 24 * 60 * 60 * 1000),
    },
  });

  console.log('Custom seed completed!');
}`}
  showLineNumbers
/>
