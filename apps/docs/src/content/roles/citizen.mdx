# Citizen Role

Citizens are public users who interact with the booking and resource management system.
They can browse listings, create bookings, and manage their personal account.

## Common Errors

<Callout variant="danger" title="booking/availability-conflict">
**Error Code:** `booking/availability-conflict`

**Cause:** The selected time slot is no longer available. Another user may have booked it while you were completing the form.

**Solution:** Choose a different time slot from the availability calendar and try again.
</Callout>

<Callout variant="danger" title="booking/validation-failed">
**Error Code:** `booking/validation-failed`

**Cause:** Required booking information is missing or invalid (e.g., missing contact details, invalid date range).

**Solution:** Review the booking form and ensure all required fields are filled correctly.
</Callout>

<Callout variant="warning" title="booking/approval-required">
**Error Code:** `booking/approval-required`

**Cause:** This listing requires approval from an organization administrator before the booking is confirmed.

**Solution:** Your booking has been submitted for review. You will receive a notification once it's approved or denied.
</Callout>

## SDK Usage Examples

<CodeBlock
  title="Fetching Listings"
  language="tsx"
  code={`import { useListings } from '@digilist/client-sdk/hooks';

function ListingBrowser() {
  const { data: listings, isLoading } = useListings({
    category: 'sports',
    status: 'available',
  });

  if (isLoading) return <Loading />;

  return (
    <ul>
      {listings.map((listing) => (
        <li key={listing.id}>{listing.title}</li>
      ))}
    </ul>
  );
}`}
  showLineNumbers
/>

<CodeBlock
  title="Creating a Booking"
  language="tsx"
  code={`import { useCreateBooking } from '@digilist/client-sdk/hooks';

function BookingForm({ listingId }) {
  const { mutate: createBooking, isPending } = useCreateBooking();

  const handleSubmit = (formData) => {
    createBooking({
      listingId,
      startTime: formData.startTime,
      endTime: formData.endTime,
      notes: formData.notes,
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      {/* Form fields */}
    </form>
  );
}`}
