# Organization Member Role

Organization members are users who represent an organization (idrettslag, kulturforening, etc.)
and manage their organization's resources, listings, and bookings within the platform.

## Common Errors

<Callout variant="danger" title="organization/access-denied">
**Error Code:** `organization/access-denied`

**Cause:** You attempted to perform an action that requires higher privileges than your current role allows.

**Solution:** Contact your organization administrator to request elevated permissions if needed.
</Callout>

<Callout variant="danger" title="listing/publish-failed">
**Error Code:** `listing/publish-failed`

**Cause:** The listing cannot be published due to missing required information or validation errors.

**Solution:** Review the listing editor for validation messages and ensure all required fields are completed.
</Callout>

<Callout variant="warning" title="booking/conflict-detected">
**Error Code:** `booking/conflict-detected`

**Cause:** Approving this booking would create a scheduling conflict with an existing reservation.

**Solution:** Review the calendar to identify the conflict. Either decline one booking or reschedule if possible.
</Callout>

<Callout variant="danger" title="organization/member-limit-reached">
**Error Code:** `organization/member-limit-reached`

**Cause:** Your organization has reached the maximum number of allowed members based on your subscription tier.

**Solution:** Contact the system administrator or upgrade your organization's subscription.
</Callout>

## SDK Usage Examples

<CodeBlock
  title="Fetching Organization Bookings"
  language="tsx"
  code={`import { useOrganizationBookings } from '@digilist/client-sdk/hooks';

function BookingQueue({ organizationId }) {
  const { data: bookings, isLoading } = useOrganizationBookings({
    organizationId,
    status: 'pending',
  });

  if (isLoading) return <Loading />;

  return (
    <ul>
      {bookings.map((booking) => (
        <BookingRequestCard key={booking.id} booking={booking} />
      ))}
    </ul>
  );
}`}
  showLineNumbers
/>

<CodeBlock
  title="Approving a Booking"
  language="tsx"
  code={`import { useApproveBooking } from '@digilist/client-sdk/hooks';

function BookingActions({ bookingId }) {
  const { mutate: approve, isPending } = useApproveBooking();

  const handleApprove = () => {
    approve({
      bookingId,
      notes: 'Approved - welcome to our facility!',
    }, {
      onSuccess: () => {
        // Booking approved, citizen notified automatically
      },
    });
  };

  return (
    <Button onClick={handleApprove} loading={isPending}>
      Approve Booking
    </Button>
  );
}`}
  showLineNumbers
/>
