# Caseworker Role

Caseworkers (saksbehandlere) are municipal employees who process applications,
manage allocations, handle disputes, and ensure compliance with booking policies.
They serve as the link between citizens, organizations, and municipal administration.

## Common Errors

<Callout variant="danger" title="allocation/period-closed">
**Error Code:** `allocation/period-closed`

**Cause:** Attempted to modify allocations outside the designated allocation period.

**Solution:** The allocation period must be reopened by an administrator. Contact your supervisor.
</Callout>

<Callout variant="danger" title="casework/unauthorized-override">
**Error Code:** `casework/unauthorized-override`

**Cause:** Attempted to perform an override action without sufficient privileges.

**Solution:** Submit an escalation request to a senior caseworker or system administrator.
</Callout>

<Callout variant="warning" title="audit/justification-required">
**Error Code:** `audit/justification-required`

**Cause:** Administrative actions require a documented justification for audit purposes.

**Solution:** Provide a clear, written justification in the designated field before proceeding.
</Callout>

<Callout variant="danger" title="organization/pending-review">
**Error Code:** `organization/pending-review`

**Cause:** This organization is under review and certain actions are restricted.

**Solution:** Complete the organization review process before performing this action.
</Callout>

## SDK Usage Examples

<CodeBlock
  title="Fetching Pending Cases"
  language="tsx"
  code={`import { useCases } from '@digilist/client-sdk/hooks';

function CaseQueue() {
  const { data: cases, isLoading } = useCases({
    status: 'pending',
    type: ['allocation', 'dispute', 'approval'],
  });

  if (isLoading) return <Loading />;

  return (
    <ul>
      {cases.map((caseItem) => (
        <CaseCard key={caseItem.id} case={caseItem} />
      ))}
    </ul>
  );
}`}
  showLineNumbers
/>

<CodeBlock
  title="Processing an Allocation"
  language="tsx"
  code={`import { useProcessAllocation } from '@digilist/client-sdk/hooks';

function AllocationActions({ allocationId, organizationId, slots }) {
  const { mutate: process, isPending } = useProcessAllocation();

  const handleApprove = () => {
    process({
      allocationId,
      decision: 'approved',
      allocatedSlots: slots,
      justification: 'Meets criteria: established organization with 200+ members',
    });
  };

  return (
    <Button onClick={handleApprove} loading={isPending}>
      Approve Allocation
    </Button>
  );
}`}
  showLineNumbers
/>

<CodeBlock
  title="Querying Audit Logs"
  language="tsx"
  code={`import { useAuditLogs } from '@digilist/client-sdk/hooks';

function AuditViewer({ entityId }) {
  const { data: logs, isLoading } = useAuditLogs({

## Compliance and Audit Requirements

<Callout variant="info" title="Audit Trail">
All caseworker actions are automatically logged with:

- **Who:** User ID and name of the caseworker
- **What:** Action performed and affected entities
- **When:** Timestamp with timezone
- **Where:** Tenant ID and IP address
- **Why:** Justification provided (when required)

These logs are retained for 7 years per Norwegian municipal regulations.
</Callout>
