# Betalingsmåter

Digilist støtter flere betalingsmåter for maksimal fleksibilitet.

## Tilgjengelige betalingsmåter

### Kort

Vi aksepterer:

- Visa
- Mastercard
- American Express

### Vipps

Betal enkelt med Vipps-appen:

1. Velg Vipps ved betaling
2. Bekreft i appen
3. Ferdig!

### Faktura

For organisasjoner kan faktura være tilgjengelig:

- Krever godkjent kreditt
- 14 dagers betalingsfrist
- Purregebyr ved forsinket betaling

## Legg til betalingsmetode

1. Gå til "Min konto" → "Betaling"
2. Klikk "Legg til betalingsmetode"
3. Velg type og fyll inn detaljer
4. Bekreft

## Sikkerhet

Alle betalinger er sikret med:

- 3D Secure autentisering
- Kryptert dataoverføring
- PCI DSS-sertifisert betalingsløsning
