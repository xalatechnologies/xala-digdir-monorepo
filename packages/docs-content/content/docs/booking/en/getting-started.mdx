# Getting Started with Booking

Welcome to Digilist! This guide helps you get started with booking venues.

## Before you begin

To book a venue, you need:

- A registered user account
- Verified email address
- Payment information (depending on the venue)

## Find a venue

1. Go to the homepage and use the search field
2. Filter by date, capacity, and facilities
3. Click on a venue to see details

## Create a booking

Once you've found a suitable venue:

1. Select desired date and time slot in the calendar
2. Add any additional services
3. Confirm the booking and pay (if required)

### Tips for first-time bookers

> 💡 **Tip:** Start by exploring venues without committing. You can add favorites to track availability.
