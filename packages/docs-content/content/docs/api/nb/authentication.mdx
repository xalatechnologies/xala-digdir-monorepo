# API-autentisering

Digilist API bruker API-nøkler og JWT-tokens for autentisering.

## Få en API-nøkkel

1. Logg inn på Tenant Admin
2. Gå til "Innstillinger" → "API"
3. Klikk "Generer ny API-nøkkel"
4. Lagre nøkkelen sikkert

> ⚠️ **Viktig:** API-nøkkelen vises kun én gang. Oppbevar den trygt!

## Bruke API-nøkkelen

Send nøkkelen i `Authorization`-headeren:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.digilist.no/v1/bookings
```

## JWT-tokens

For brukerbasert autentisering:

1. POST til `/auth/login` med brukernavn/passord
2. Motta JWT-token i responsen
3. Bruk token i påfølgende requests

## Rate limiting

- 100 requests per minutt per API-nøkkel
- 429 status kode ved overskridelse
- Retry-After header angir ventetid

## Feilsøking

- **401 Unauthorized:** Ugyldig eller manglende API-nøkkel
- **403 Forbidden:** Mangler tilgang til ressursen
- **429 Too Many Requests:** Rate limit nådd
