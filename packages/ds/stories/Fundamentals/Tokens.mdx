# Design Tokens

Design Tokens are flexible variables that can be used independently of technology or design tools. This reference shows all tokens generated by the [Designsystemet CLI](https://designsystemet.no/no/fundamentals/design-elements/variables).

> "Design Tokens er fleksible variabler som kan benyttes uavhengig av teknologi eller designverktøy."
> — Designsystemet

## Token Categories

### Colors

Colors are contextual - they change based on the `data-color` attribute.

#### Available Color Contexts

| Context | Usage |
|---------|-------|
| `accent` | Primary brand actions |
| `brand1` | Secondary brand |
| `brand2` | Tertiary brand |
| `brand3` | Quaternary brand |
| `neutral` | Gray tones, borders, text |
| `success` | Success states |
| `danger` | Error/danger states |
| `warning` | Warning states |
| `info` | Informational states |

#### Color Token Structure

```css
/* Background colors */
--ds-color-background-default    /* Page background */
--ds-color-background-tinted     /* Tinted background */

/* Surface colors (cards, panels) */
--ds-color-surface-default       /* Default surface */
--ds-color-surface-tinted        /* Tinted surface */
--ds-color-surface-hover         /* Hover state */
--ds-color-surface-active        /* Active/pressed state */

/* Border colors */
--ds-color-border-subtle         /* Light borders */
--ds-color-border-default        /* Default borders */
--ds-color-border-strong         /* Emphasized borders */

/* Text colors */
--ds-color-text-subtle           /* Secondary text */
--ds-color-text-default          /* Primary text */

/* Base colors (buttons, interactive) */
--ds-color-base-default          /* Default state */
--ds-color-base-hover            /* Hover state */
--ds-color-base-active           /* Active state */
--ds-color-base-contrast-subtle  /* Contrast for icons */
--ds-color-base-contrast-default /* Contrast for text */
```

#### Using Color Contexts

```tsx
// Accent/brand context
<div data-color="accent">
  <Button>Primary Action</Button>
  {/* Button uses --ds-color-base-default from accent palette */}
</div>

// Danger context
<div data-color="danger">
  <Button>Delete</Button>
  {/* Button uses --ds-color-base-default from danger palette */}
</div>
```

## Data Attributes

### Color Scheme

```html
<!-- On <html> element -->
<html data-color-scheme="light">  <!-- Light mode -->
<html data-color-scheme="dark">   <!-- Dark mode -->
<html data-color-scheme="auto">   <!-- System preference -->
```

### Size Scale

```html
<!-- On <html> element or container -->
<html data-size="sm">  <!-- Small -->
<html data-size="md">  <!-- Medium (default) -->
<html data-size="lg">  <!-- Large -->
```

### Color Context

```html
<!-- On any container -->
<div data-color="accent">...</div>
<div data-color="danger">...</div>
<div data-color="success">...</div>
```

## Usage Examples

### Component Styling

```tsx
// Card with proper tokens
<div style={{
  padding: 'var(--ds-size-6)',
  backgroundColor: 'var(--ds-color-surface-default)',
  borderRadius: 'var(--ds-border-radius-md)',
  border: 'var(--ds-border-width-default) solid var(--ds-color-border-default)',
  boxShadow: 'var(--ds-shadow-sm)',
}}>
  <h2 style={{
    fontSize: 'var(--ds-heading-md-font-size)',
    fontWeight: 'var(--ds-heading-md-font-weight)',
    lineHeight: 'var(--ds-heading-md-line-height)',
    color: 'var(--ds-color-text-default)',
  }}>
    Title
  </h2>
  <p style={{
    fontSize: 'var(--ds-body-md-font-size)',
    lineHeight: 'var(--ds-body-md-line-height)',
    color: 'var(--ds-color-text-subtle)',
  }}>
    Description
  </p>
</div>
```

### Responsive Sizing

```tsx
// Container that respects size attribute
<div style={{
  padding: 'var(--ds-size-4)',  // 16px at md, scales at sm/lg
  gap: 'var(--ds-size-2)',      // 8px at md, scales at sm/lg
}}>
  {children}
</div>
```

## Best Practices

### Do

```tsx
// Use semantic tokens
backgroundColor: 'var(--ds-color-surface-default)'
color: 'var(--ds-color-text-default)'
padding: 'var(--ds-size-4)'

// Use data-color for context
<div data-color="danger">
  <Alert>Error message</Alert>
</div>
```

### Don't

```tsx
// Raw values
backgroundColor: '#ffffff'
color: '#333333'
padding: '16px'

// Mixing token systems
padding: '1rem'
margin: 'var(--ds-size-4)'
```

## Token Generation

Tokens are generated using the Designsystemet CLI:

```bash
# Create tokens from config
npx @digdir/designsystemet@latest tokens create --config designsystemet.config.json

# Build CSS from tokens
npx @digdir/designsystemet@latest tokens build --config designsystemet.config.json
```
