# DataTable

A feature-rich table component for displaying and interacting with data collections.

## Features

### Sorting

Click column headers to sort. Sortable columns are indicated with icons.

```tsx
const columns = [
  { accessorKey: 'name', header: 'Name', sortable: true },
  { accessorKey: 'email', header: 'Email', sortable: true },
];
```

### Custom Cell Rendering

Use the `cell` property to render custom content:

```tsx
{
  accessorKey: 'status',
  header: 'Status',
  cell: ({ row }) => (
    <Badge variant={row.status === 'active' ? 'success' : 'neutral'}>
      {row.status}
    </Badge>
  ),
}
```

## Accessibility

### Keyboard Navigation

| Key | Action |
|-----|--------|
| `Tab` | Move between interactive elements |
| `Enter` | Activate focused element |
| `Space` | Toggle selection (if selectable) |
| `Arrow Up/Down` | Navigate rows |

### Screen Reader Support

- Table structure is announced (rows, columns)
- Sortable columns indicate sort direction
- Selection state is announced
- Empty/loading states are announced

### Focus Management

- Focus trap within table during keyboard navigation
- Clear focus indicators on all interactive elements

## Do and Don't

### Do

- Use consistent column widths
- Provide loading and empty states
- Use semantic column headers
- Enable sorting for relevant columns
- Paginate large datasets

### Don't

- Overload with too many columns
- Hide important data in horizontal scroll
- Use complex nested content in cells
- Forget loading states for async data

## data-testid Convention

```tsx
<DataTable data-testid="users-table" />

// Access specific elements
await page.getByTestId('users-table'); // Table container
await page.getByTestId('table-row-123'); // Specific row
await page.getByTestId('table-header-name'); // Column header
```

## Thin App Usage

In your app, use DataTable as a thin wrapper:

```tsx
// App component - thin wrapper
import { DataTable } from '@xala/ds';
import { useUsers } from '@/hooks/useUsers';

function UsersTable() {
  const { data, isLoading } = useUsers();
  
  return (
    <DataTable
      columns={userColumns}
      data={data ?? []}
      loading={isLoading}
      emptyMessage="No users found"
      data-testid="users-table"
    />
  );
}
```

## Migration Notes

If migrating from a custom table:

1. Replace with DS `DataTable`
2. Convert column definitions to `ColumnDef` format
3. Move cell rendering logic to `cell` property
4. Use DS `Badge` for status indicators
5. Use DS loading and empty state patterns
