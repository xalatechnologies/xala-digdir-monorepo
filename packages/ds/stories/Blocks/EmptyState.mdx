# EmptyState

Empty state patterns for displaying when no data is available.

<Canvas of={EmptyStateStories.NoResults} />

## Features

- **Icon** - Optional visual indicator
- **Title** - Clear heading describing the state
- **Description** - Helpful explanation text
- **Action** - CTA to resolve the empty state

## When to Use

Use EmptyState for:
- No search results
- Empty lists or tables
- First-time user experiences
- Error recovery states

## Accessibility

### Screen Reader Support
- Heading announces the state
- Description provides context
- Action buttons are accessible

### Focus Management
- Action button is focusable
- Clear focus indicators

## Do and Don't

### Do
- Provide clear, actionable guidance
- Use appropriate icons for context
- Include a primary action when possible
- Keep descriptions concise

### Don't
- Use technical jargon
- Leave users without next steps
- Make empty states feel like errors (unless they are)
- Use the same empty state for all scenarios

## Thin App Integration

```tsx
import { Button, Heading, Paragraph } from '../../src';
import { SearchIcon } from '@xala/ds';

function SearchResults({ results, onClearFilters }) {
  if (results.length === 0) {
    return (
      <div style={{
        display: 'flex',
        flexDirection: 'column',
        alignItems: 'center',
        padding: 'var(--ds-spacing-10)',
        textAlign: 'center',
      }}>
        <SearchIcon style={{ fontSize: '3rem', opacity: 0.5 }} />
        <Heading level={3} data-size="sm">
          {t('search.noResults')}
        </Heading>
        <Paragraph>
          {t('search.tryAdjusting')}
        </Paragraph>
        <Button variant="secondary" onClick={onClearFilters}>
          {t('search.clearFilters')}
        </Button>
      </div>
    );
  }

  return <ResultsList results={results} />;
}
```

## Pattern Variants

| Variant | When to Use |
|---------|-------------|
| No Results | Search/filter returned nothing |
| Empty List | Collection has no items yet |
| Error | Something went wrong |
| First Time | New user onboarding |
