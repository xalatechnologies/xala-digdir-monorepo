# ListToolbar

The ListToolbar block provides a consistent toolbar pattern for list and grid pages, combining search, filters, sort options, and actions.

<Canvas of={ListToolbarStories.Default} />

## Props

<Controls of={ListToolbarStories.Default} />

## Features

- **Search** - Debounced text search with configurable placeholder
- **Filters** - Dropdown filter buttons with active state indicators
- **Sort** - Sort options dropdown
- **Results count** - Display total results with custom label
- **Primary action** - Slot for main action button

## When to Use

Use ListToolbar when you need:
- A toolbar above lists, grids, or tables
- Search functionality with filters
- Consistent UI pattern across list pages

## Accessibility

### Keyboard Navigation
- `Tab` navigates between controls
- `Enter` or `Space` activates buttons
- `Escape` closes filter dropdowns

### Screen Reader Support
- Search input announced as search field
- Filter buttons have proper labels
- Results count announced on change

## Do and Don't

### Do
- Use consistent filter patterns across pages
- Provide clear filter labels
- Show active filter count when filters are applied
- Include results count for context

### Don't
- Overload with too many filters (max 4-5 recommended)
- Use unclear filter labels
- Hide essential search functionality
- Forget to handle empty filter states

## Thin App Integration

```tsx
// In your app page component
import { ListToolbar } from '@xala/ds';

function ListingsPage() {
  const [search, setSearch] = useState('');
  const [filters, setFilters] = useState({});
  const [sort, setSort] = useState('date-desc');
  
  const { data } = useListings({ search, filters, sort });

  return (
    <>
      <ListToolbar
        search={{
          value: search,
          onChange: setSearch,
          placeholder: t('listings.search'),
        }}
        filters={filterConfig}
        activeFilters={filters}
        onFilterChange={(id, value) => 
          setFilters(prev => ({ ...prev, [id]: value }))
        }
        sortOptions={sortOptions}
        sortValue={sort}
        onSortChange={setSort}
        resultsCount={data?.total}
        resultsLabel={t('listings.results')}
        primaryAction={
          <Button variant="primary" onClick={openCreateModal}>
            {t('listings.create')}
          </Button>
        }
      />
      <ListingGrid items={data?.items} />
    </>
  );
}
```

## Migration Notes

If migrating from custom toolbar implementations:

1. Replace custom search inputs with `search` prop
2. Convert filter state to `activeFilters` Record format
3. Use `onFilterChange(id, value)` callback pattern
4. Move action buttons to `primaryAction` slot
