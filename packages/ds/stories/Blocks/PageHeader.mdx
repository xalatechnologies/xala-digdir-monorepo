# PageHeader

The PageHeader block provides a consistent header pattern for pages, including title, subtitle, breadcrumbs, and actions.

<Canvas of={PageHeaderStories.Default} />

## Props

<Controls of={PageHeaderStories.Default} />

## Features

- **Title** - Main page heading (h1 by default)
- **Subtitle** - Optional description text
- **Breadcrumbs** - Navigation context
- **Actions** - Slot for action buttons
- **Bordered** - Optional bottom border
- **Heading level** - Configurable (1-6)

## When to Use

Use PageHeader at the top of every main content page to:
- Establish page context with title
- Show navigation path with breadcrumbs
- Provide page-level actions

## Accessibility

### Keyboard Navigation
- Action buttons accessible via Tab
- Breadcrumb links navigable

### Screen Reader Support
- Title uses semantic heading element
- Breadcrumbs use nav landmark
- Actions announced appropriately

### Heading Hierarchy
- Default level is h1 for main pages
- Use level 2+ for nested sections

## Do and Don't

### Do
- Use on every main content page
- Keep titles concise and descriptive
- Include breadcrumbs for nested pages
- Place primary action on the right

### Don't
- Use multiple h1 headings on a page
- Make titles too long (max 50 characters)
- Overload with too many actions (max 3)
- Skip heading levels (h1 to h3)

## Thin App Integration

```tsx
// In your app page component
import { PageHeader } from '@xala/ds';
import { Breadcrumbs, Button } from '../../src';

function BookingDetailsPage({ booking }) {
  return (
    <>
      <PageHeader
        title={booking.title}
        subtitle={`Booking #${booking.id}`}
        breadcrumb={
          <Breadcrumbs>
            <Breadcrumbs.Link href="/">Dashboard</Breadcrumbs.Link>
            <Breadcrumbs.Link href="/bookings">Bookings</Breadcrumbs.Link>
            <span>{booking.id}</span>
          </Breadcrumbs>
        }
        actions={
          <div style={{ display: 'flex', gap: 'var(--ds-spacing-2)' }}>
            <Button variant="secondary" onClick={handleEdit}>
              Edit
            </Button>
            <Button variant="primary" onClick={handleConfirm}>
              Confirm
            </Button>
          </div>
        }
      />
      <BookingDetails booking={booking} />
    </>
  );
}
```

## Migration Notes

If migrating from custom header implementations:

1. Replace custom heading elements with PageHeader
2. Move breadcrumb navigation to `breadcrumb` prop
3. Move action buttons to `actions` slot
4. Use `bordered` prop instead of custom CSS
5. Set appropriate `level` for heading hierarchy
