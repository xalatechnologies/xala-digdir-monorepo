# Xala Design System (@xala/ds)

> A production-ready component library built on [Digdir Designsystemet](https://designsystemet.no)

The Xala Design System provides a comprehensive set of components, patterns, and guidelines for building consistent, accessible, and maintainable applications for the Norwegian public sector.

## What is Designsystemet?

Designsystemet is Norway's national design system - a shared digital toolbox with fundamental UI components, guidelines, and patterns. It enables efficient product development and holistic user experiences across public services.

**Key Resources:**
- [Designsystemet Documentation](https://designsystemet.no/no)
- [Theme Builder](https://theme.designsystemet.no/)
- [GitHub Repository](https://github.com/digdir/designsystemet)
- [Slack Community](https://designsystemet.no/slack)

## Why @xala/ds?

`@xala/ds` extends Designsystemet with:

| Feature | Description |
|---------|-------------|
| **Facade Pattern** | Single import point for all UI components |
| **Business Blocks** | Domain-specific components (booking, rental objects, GDPR) |
| **Application Shells** | Pre-built layouts for common app structures |
| **Thin App Strategy** | Apps focus on data fetching; DS handles all UI |

## Component Hierarchy

The DS follows a layered architecture, matching the Norwegian design system's approach:

```
     SHELLS (AppShell, DashboardLayout)
           ↑
     BLOCKS (RentalObjectCard, BookingForm)
           ↑
     COMPOSED (PageHeader, DataTable, FilterBar)
           ↑
     PRIMITIVES (Button, Card, Input, Grid)
           ↑
     DESIGNSYSTEMET (@digdir/designsystemet-react)
```

### Layer 1: Primitives
Re-exported from `@digdir/designsystemet-react`:
- **Layout:** Container, Grid, Stack, LayoutGrid
- **Forms:** Button, Input, Select, Checkbox, Radio, Textarea, Switch
- **Display:** Card, Badge, Avatar, Progress, Spinner
- **Typography:** Heading, Paragraph, Label, Text
- **Feedback:** Alert, Toast, Dialog, Tooltip
- **Navigation:** Tabs, Breadcrumb, Link, Pagination

### Layer 2: Composed
Custom mid-level components:
- **Layout:** ContentLayout, ContentSection, PageHeader
- **Navigation:** Navigation, NavigationLink, Sidebar, Drawer
- **Forms:** FilterBar, DataPageToolbar, Wizard, Stepper
- **Display:** DataTable, ListToolbar, EmptyState, StatusTabs

### Layer 3: Blocks
Business-domain components:
- **Rental Objects:** RentalObjectCard, RentalObjectGrid, RentalObjectMap
- **Booking:** BookingFormModal, BookingStepper, AvailabilityCalendar
- **Admin:** PermissionMatrix, ScopeSelector, UserInviteForm
- **GDPR:** ConsentPopup, ConsentSettings, DataSubjectRequestForm

### Layer 4: Shells
Application-level layouts:
- **AppShell** - Complete application container
- **DashboardSidebar** - Navigation sidebar
- **DashboardContent** - Main content area

## Design Principles

### 1. Universell Utforming (Accessibility)

Designsystemet meets WCAG requirements included in Norwegian regulations. Every component is:
- Keyboard navigable
- Screen reader compatible
- WCAG 2.1 AA compliant
- Tested with axe-core

> "Universell utforming er en del av hele vår arbeidsprosess - fra vi begynner å spesifisere komponenten til den er i produksjon."
> — Designsystemet

### 2. Token-First Styling

All styling uses design tokens. No raw CSS values are permitted:

```tsx
// Correct - uses tokens
<div style={{ padding: 'var(--ds-spacing-4)' }}>

// Incorrect - raw CSS values
<div style={{ padding: '16px' }}>
```

### 3. Thin Apps, Rich DS

Applications should be thin wrappers. All UI logic lives in the DS:

```tsx
// App code - thin wrapper
import { RentalObjectGrid, AppShell } from '@xala/ds';

function ListingsPage() {
  const { data } = useListings();
  return (
    <AppShell>
      <RentalObjectGrid items={data} />
    </AppShell>
  );
}
```

### 4. SDK-Driven Data

Components expect data from `@digilist/client-sdk`:

```tsx
import { useListings } from '@digilist/client-sdk/hooks';
import { RentalObjectGrid } from '@xala/ds';

function Page() {
  const { data, isLoading } = useListings();
  if (isLoading) return <Spinner />;
  return <RentalObjectGrid items={data} />;
}
```

## Critical Rules

```
NEVER import @digdir/* directly in apps
NEVER use inline styles with raw values
NEVER create UI components in apps
ALWAYS import from @xala/ds
ALWAYS use design tokens
ALWAYS add Storybook stories for new components
```
