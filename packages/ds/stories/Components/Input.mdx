# Input (Textfield)

The Input component (Textfield from Digdir) provides text entry functionality with labels, descriptions, and validation states.

<Canvas of={InputStories.Default} />

## Features

- **Label** - Required label above the input
- **Description** - Optional helper text
- **Error** - Validation error message
- **Disabled** - Non-interactive state
- **Read-only** - View-only state

## When to Use

Use Input for:
- Single-line text entry
- Email, phone, password fields
- Search inputs
- Form fields

## Accessibility

### Keyboard Navigation
- Standard input behavior
- Tab to focus, type to enter text

### Screen Reader Support
- Label announced on focus
- Error messages announced
- Description read as accessible description

### Focus Indicators
- Clear focus ring on tab navigation

## Do and Don't

### Do
- Always provide a label
- Use appropriate input types (email, tel, password)
- Show clear error messages
- Use description for format hints

### Don't
- Use placeholder as label replacement
- Make error messages vague
- Disable without explanation
- Use for multi-line text (use Textarea)

## Thin App Integration

```tsx
import { Textfield } from '../../src';
import { useForm } from 'react-hook-form';

function ContactForm() {
  const { register, formState: { errors } } = useForm();

  return (
    <form>
      <Textfield
        label={t('form.name')}
        error={errors.name?.message}
        {...register('name', { required: t('validation.required') })}
      />
      <Textfield
        label={t('form.email')}
        type="email"
        error={errors.email?.message}
        {...register('email', { 
          required: t('validation.required'),
          pattern: { value: /^[^@]+@[^@]+$/, message: t('validation.email') }
        })}
      />
    </form>
  );
}
```
