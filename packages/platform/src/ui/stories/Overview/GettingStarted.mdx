# Getting Started with @xala/ds

This guide walks you through setting up and using the Xala Design System, following the patterns established by [Designsystemet](https://designsystemet.no/no/fundamentals/introduction/get-started).

## Prerequisites

- Node.js 20+
- pnpm (workspace package manager)
- TypeScript knowledge

## Installation

The DS is a workspace package in the monorepo:

```json
// In your app's package.json
{
  "dependencies": {
    "@xala/ds": "workspace:*"
  }
}
```

## Setup Steps

### Step 1: Import Styles (Once)

Import DS styles in your application entry point:

```tsx
// main.tsx - import ONCE at the app root
import '@xala/ds/styles';
```

This imports:
- Digdir Designsystemet CSS
- Design tokens (colors, spacing, typography)
- Component styles
- Theme CSS for selected theme

### Step 2: Add the Provider

Wrap your application with `DesignsystemetProvider`:

```tsx
import { DesignsystemetProvider } from '@xala/ds';

function App() {
  return (
    <DesignsystemetProvider
      theme="digdir"
      colorScheme="auto"
      size="md"
      typography="primary"
    >
      <RouterProvider router={router} />
    </DesignsystemetProvider>
  );
}
```

**Provider Props:**

| Prop | Values | Default | Description |
|------|--------|---------|-------------|
| `theme` | `digdir`, `altinn`, `uutilsynet`, `portal` | `digdir` | Visual theme |
| `colorScheme` | `light`, `dark`, `auto` | `auto` | Color mode |
| `size` | `sm`, `md`, `lg` | `md` | Component size scale |
| `typography` | `primary`, `secondary` | `primary` | Font family |

### Step 3: Use Components

Import components from `@xala/ds`:

```tsx
import {
  // Primitives
  Button,
  Card,
  Grid,
  Heading,
  Input,

  // Composed
  PageHeader,
  DataTable,
  FilterBar,

  // Blocks
  RentalObjectCard,
  BookingFormModal,

  // Shells
  AppShell,
} from '@xala/ds';
```

## Complete Example

```tsx
// main.tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { QueryClientProvider } from '@tanstack/react-query';
import { DesignsystemetProvider } from '@xala/ds';
import { queryClient, initializeClient } from '@digilist/client-sdk';
import '@xala/ds/styles';
import { App } from './App';

// Initialize SDK
initializeClient({
  baseUrl: import.meta.env.VITE_API_URL,
  tenantId: import.meta.env.VITE_TENANT_ID,
});

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <QueryClientProvider client={queryClient}>
      <DesignsystemetProvider theme="digdir" colorScheme="auto">
        <App />
      </DesignsystemetProvider>
    </QueryClientProvider>
  </React.StrictMode>
);
```

## Theme Customization

Designsystemet supports custom themes through the [Theme Builder](https://theme.designsystemet.no/).

### Using Built-in Themes

```tsx
<DesignsystemetProvider theme="altinn">
  {/* App uses Altinn theme */}
</DesignsystemetProvider>
```

### Theme Switching at Runtime

```tsx
import { useTheme } from '@xala/ds';

function ThemeSelector() {
  const { theme, setTheme, colorScheme, setColorScheme } = useTheme();

  return (
    <>
      <Select value={theme} onChange={(e) => setTheme(e.target.value)}>
        <option value="digdir">Digdir</option>
        <option value="altinn">Altinn</option>
        <option value="portal">Portal</option>
      </Select>

      <Button onClick={() => setColorScheme(colorScheme === 'light' ? 'dark' : 'light')}>
        Toggle Dark Mode
      </Button>
    </>
  );
}
```

## Using Design Tokens

Always use CSS variables for styling:

```tsx
// Spacing
style={{
  padding: 'var(--ds-spacing-4)',      // 16px
  gap: 'var(--ds-spacing-2)',          // 8px
  margin: 'var(--ds-spacing-6)',       // 24px
}}

// Colors (with data-color attribute)
style={{
  color: 'var(--ds-color-text-default)',
  backgroundColor: 'var(--ds-color-surface-default)',
  borderColor: 'var(--ds-color-border-default)',
}}

// Typography
style={{
  fontSize: 'var(--ds-font-size-4)',
  fontWeight: 'var(--ds-font-weight-medium)',
  lineHeight: 'var(--ds-line-height-md)',
}}

// Borders
style={{
  borderRadius: 'var(--ds-border-radius-md)',
  borderWidth: 'var(--ds-border-width-default)',
}}

// Shadows
style={{
  boxShadow: 'var(--ds-shadow-md)',
}}
```

## Semantic Color Usage

Colors are semantic - they change based on context:

```tsx
// Accent colors (brand)
<div data-color="accent">
  {/* Uses --ds-color-* tokens with accent values */}
</div>

// Danger colors (errors)
<div data-color="danger">
  {/* Uses --ds-color-* tokens with danger values */}
</div>

// Success colors
<div data-color="success">
  {/* Uses --ds-color-* tokens with success values */}
</div>
```

## Responsive Sizing

Use the `data-size` attribute for responsive components:

```tsx
// Small components
<div data-size="sm">
  <Button>Small Button</Button>
</div>

// Medium (default)
<div data-size="md">
  <Button>Medium Button</Button>
</div>

// Large
<div data-size="lg">
  <Button>Large Button</Button>
</div>
```

## Testing

### data-testid Convention

All interactive components support `data-testid`:

```tsx
<Button data-testid="submit-button">Submit</Button>
<DataTable data-testid="users-table" columns={columns} data={data} />
<Input data-testid="email-input" type="email" />
```

### Playwright Testing

```tsx
// tests/e2e/example.spec.ts
import { test, expect } from '@playwright/test';

test('should submit form', async ({ page }) => {
  await page.goto('/form');

  await page.getByTestId('email-input').fill('test@example.com');
  await page.getByTestId('submit-button').click();

  await expect(page.getByTestId('success-message')).toBeVisible();
});
```

## Troubleshooting

### Styles Not Loading

```tsx
// Ensure you import styles in main.tsx
import '@xala/ds/styles';
```

### Theme Not Applied

```tsx
// Ensure DesignsystemetProvider wraps your app
<DesignsystemetProvider theme="digdir">
  <App />
</DesignsystemetProvider>
```

### TypeScript Errors

```tsx
// Import types explicitly
import type { ButtonProps, DataTableProps } from '@xala/ds';
```

### Component Not Found

```tsx
// Check the component is exported from index.ts
// All components should be importable from '@xala/ds'
import { ComponentName } from '@xala/ds';
```
