# Theme Builder (Temabygger)

Designsystemet supports custom visual identities through themes. The [Theme Builder](https://theme.designsystemet.no/) allows you to create custom themes with your own colors and preferences.

> "Designsystemet er laget for å kunne brukes sammen med din egen visuelle profil - inkludert farger og andre preferanser."
> — [Designsystemet](https://designsystemet.no/no/fundamentals/themebuilder/own-theme)

## Available Themes in @xala/ds

| Theme | Description | Usage |
|-------|-------------|-------|
| `digdir` | Default Digitaliseringsdirektoratet theme | General purpose |
| `altinn` | Altinn platform theme | Altinn-related services |
| `uutilsynet` | Tilsynet for universell utforming | Accessibility-focused |
| `portal` | Portal theme | Public-facing portals |
| `digilist` | Digilist custom theme | Digilist platform |

## Using Themes

### Basic Theme Selection

```tsx
import { DesignsystemetProvider } from '@xala/ds';

function App() {
  return (
    <DesignsystemetProvider theme="digdir">
      <YourApp />
    </DesignsystemetProvider>
  );
}
```

### Dynamic Theme Switching

```tsx
import { useTheme } from '@xala/ds';

function ThemeSelector() {
  const { theme, setTheme } = useTheme();

  return (
    <Select value={theme} onChange={(e) => setTheme(e.target.value)}>
      <option value="digdir">Digdir</option>
      <option value="altinn">Altinn</option>
      <option value="portal">Portal</option>
    </Select>
  );
}
```

### Color Scheme (Dark Mode)

```tsx
import { useTheme } from '@xala/ds';

function ColorSchemeToggle() {
  const { colorScheme, setColorScheme } = useTheme();

  return (
    <Switch
      checked={colorScheme === 'dark'}
      onChange={(checked) => setColorScheme(checked ? 'dark' : 'light')}
    >
      Mørk modus
    </Switch>
  );
}
```

## Creating Custom Themes

### Step 1: Theme Configuration

Create a `designsystemet.config.json` file:

```json
{
  "outDir": "./design-tokens",
  "clean": true,
  "themes": {
    "my-theme": {
      "colors": {
        "main": {
          "primary": "#0062BA",
          "accent": "#1E98F5"
        },
        "neutral": "#1E2B3C",
        "support": {
          "extra1": "#F45F63",
          "extra2": "#E5AA20"
        }
      },
      "borderRadius": 4
    }
  }
}
```

### Step 2: Generate Tokens

```bash
# Create design tokens
npx @digdir/designsystemet@latest tokens create --config designsystemet.config.json

# Build CSS
npx @digdir/designsystemet@latest tokens build --config designsystemet.config.json
```

### Step 3: Use in @xala/ds

Add your theme to `packages/ds-themes/`:

```
packages/ds-themes/
├── themes/
│   ├── digdir/
│   ├── altinn/
│   └── my-theme/          # Your custom theme
│       ├── tokens.css
│       └── variables.css
```

### Step 4: Register Theme

Update `packages/ds/src/ThemeProvider.tsx`:

```tsx
const themes = {
  digdir: () => import('@xala/ds-themes/themes/digdir/tokens.css'),
  altinn: () => import('@xala/ds-themes/themes/altinn/tokens.css'),
  'my-theme': () => import('@xala/ds-themes/themes/my-theme/tokens.css'),
};
```

## Theme Builder Workflow

```
1. Visit https://theme.designsystemet.no/
         ↓
2. Configure colors and preferences
         ↓
3. Click "Ta i bruk tema"
         ↓
4. Copy config JSON
         ↓
5. Save as designsystemet.config.json
         ↓
6. Run: npx @digdir/designsystemet@latest tokens create
         ↓
7. Run: npx @digdir/designsystemet@latest tokens build
         ↓
8. Import generated CSS in your app
```

## Color Semantics

Themes define semantic color scales:

### Main Colors

| Token | Usage |
|-------|-------|
| `--ds-color-accent-*` | Primary brand color |
| `--ds-color-brand1-*` | Secondary brand color |
| `--ds-color-brand2-*` | Tertiary brand color |
| `--ds-color-brand3-*` | Quaternary brand color |

### Semantic Colors

| Token | Usage |
|-------|-------|
| `--ds-color-neutral-*` | Neutral/gray tones |
| `--ds-color-success-*` | Success states |
| `--ds-color-danger-*` | Error/danger states |
| `--ds-color-warning-*` | Warning states |
| `--ds-color-info-*` | Informational states |

### Color Variations

Each color has variations for different contexts:

```css
/* Background colors */
--ds-color-background-default
--ds-color-background-tinted

/* Surface colors */
--ds-color-surface-default
--ds-color-surface-tinted
--ds-color-surface-hover
--ds-color-surface-active

/* Border colors */
--ds-color-border-subtle
--ds-color-border-default
--ds-color-border-strong

/* Text colors */
--ds-color-text-subtle
--ds-color-text-default

/* Base colors (for buttons, etc.) */
--ds-color-base-default
--ds-color-base-hover
--ds-color-base-active
--ds-color-base-contrast-subtle
--ds-color-base-contrast-default
```

## Using Semantic Colors

### With data-color Attribute

```tsx
// Accent color context
<div data-color="accent">
  <Button>Primary Action</Button>
</div>

// Danger color context
<div data-color="danger">
  <Button>Delete</Button>
</div>

// Success color context
<div data-color="success">
  <Alert>Operation successful</Alert>
</div>
```

### Direct CSS Variable Usage

```tsx
// In styled components or inline styles
<div style={{
  backgroundColor: 'var(--ds-color-surface-default)',
  color: 'var(--ds-color-text-default)',
  borderColor: 'var(--ds-color-border-default)',
}}>
  Content
</div>
```

## Size Scaling

Themes support three size scales:

| Size | Use Case |
|------|----------|
| `sm` | Compact UIs, mobile views |
| `md` | Default, general purpose |
| `lg` | Accessible, large touch targets |

```tsx
<DesignsystemetProvider size="lg">
  {/* All components render larger */}
</DesignsystemetProvider>
```

## Best Practices

### 1. Use Semantic Tokens

```tsx
// Correct - semantic token
style={{ color: 'var(--ds-color-text-default)' }}

// Incorrect - hardcoded color
style={{ color: '#333333' }}
```

### 2. Test Both Color Schemes

```tsx
// Test component in light and dark modes
export const LightMode: Story = {
  decorators: [(Story) => (
    <div data-color-scheme="light"><Story /></div>
  )],
};

export const DarkMode: Story = {
  decorators: [(Story) => (
    <div data-color-scheme="dark"><Story /></div>
  )],
};
```

### 3. Respect User Preferences

```tsx
// Auto respects prefers-color-scheme
<DesignsystemetProvider colorScheme="auto">
```

### 4. Maintain Contrast

Always verify contrast ratios when customizing themes. Use the [Theme Builder](https://theme.designsystemet.no/) which automatically generates accessible color scales.
