# Patterns (Mønstre)

Patterns are guidelines and recommendations for how interactions and recurring user tasks should be solved. When the same patterns are used across services, we create recognizable user experiences.

> "Klarer vi å etablere felles mønstre blir det lettere for en bruker som har gjort noe et sted å kjenne igjen og forstå hvordan det skal gjøres et annet sted."
> — [Designsystemet](https://designsystemet.no/no/patterns)

## Established Patterns from Designsystemet

These patterns have been agreed upon by the cross-agency working group (Digdir, Nav, Skatteetaten, Brønnøysundregistrene, Oslo kommune).

### Required and Optional Fields

**Pattern:** Mark optional fields, not required ones.

```tsx
// Correct - Mark optional fields
<Field label="E-post">
  <Input type="email" required />
</Field>

<Field label="Telefon (valgfritt)">
  <Input type="tel" />
</Field>

// Incorrect - Asterisks for required
<Field label="E-post *">
  <Input type="email" required />
</Field>
```

**Rationale:**
- Most form fields are required
- Marking optional fields reduces cognitive load
- Cleaner visual appearance

> Reference: [Obligatoriske og valgfrie skjemafelt](https://designsystemet.no/no/patterns/required-and-optional-fields)

### User-Triggered Error Messages

**Pattern:** Show validation errors after user interaction, not on page load.

```tsx
// Form validation pattern
function FormField({ name, label, validate }) {
  const [value, setValue] = useState('');
  const [touched, setTouched] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const handleBlur = () => {
    setTouched(true);
    const validationError = validate(value);
    setError(validationError);
  };

  return (
    <Field
      label={label}
      error={touched ? error : undefined}
    >
      <Input
        value={value}
        onChange={(e) => setValue(e.target.value)}
        onBlur={handleBlur}
        aria-invalid={touched && !!error}
      />
    </Field>
  );
}
```

**When to show errors:**
- After user leaves the field (onBlur)
- After form submission attempt
- NOT on initial page load
- NOT while user is typing

> Reference: [Brukerutløste feilmeldinger](https://designsystemet.no/no/patterns/errors)

### System Notifications

**Pattern:** Consistent display of system-generated alerts and notifications.

```tsx
// Success notification
<Alert variant="success" role="status">
  <Alert.Heading>Booking bekreftet</Alert.Heading>
  <Paragraph>Du vil motta en bekreftelse på e-post.</Paragraph>
</Alert>

// Warning notification
<Alert variant="warning" role="alert">
  <Alert.Heading>Sesjonen utløper snart</Alert.Heading>
  <Paragraph>Du blir logget ut om 5 minutter.</Paragraph>
  <Button variant="secondary">Forleng sesjon</Button>
</Alert>

// Error notification
<Alert variant="danger" role="alert" aria-live="assertive">
  <Alert.Heading>Kunne ikke lagre endringer</Alert.Heading>
  <Paragraph>Prøv igjen eller kontakt support.</Paragraph>
</Alert>

// Info notification
<Alert variant="info" role="status">
  <Alert.Heading>Planlagt vedlikehold</Alert.Heading>
  <Paragraph>Systemet vil være utilgjengelig lørdag kl. 02:00-04:00.</Paragraph>
</Alert>
```

**Notification placement:**
- Page-level: Top of content area
- Form-level: Above the form
- Field-level: Below the field

> Reference: [Systemvarsler](https://designsystemet.no/no/patterns/systemnotifications)

## Xala Platform Patterns

### Booking Flow Pattern

Standard pattern for multi-step booking:

```tsx
function BookingWizard() {
  const [step, setStep] = useState(1);

  return (
    <Wizard currentStep={step} totalSteps={4}>
      <Wizard.Header>
        <Wizard.Step number={1} label="Velg dato" />
        <Wizard.Step number={2} label="Velg tid" />
        <Wizard.Step number={3} label="Dine opplysninger" />
        <Wizard.Step number={4} label="Bekreft" />
      </Wizard.Header>

      <Wizard.Content>
        {step === 1 && <DateSelectionStep />}
        {step === 2 && <TimeSelectionStep />}
        {step === 3 && <ContactInfoStep />}
        {step === 4 && <ConfirmationStep />}
      </Wizard.Content>

      <Wizard.Actions>
        {step > 1 && (
          <Button variant="secondary" onClick={() => setStep(s => s - 1)}>
            Forrige
          </Button>
        )}
        {step < 4 ? (
          <Button variant="primary" onClick={() => setStep(s => s + 1)}>
            Neste
          </Button>
        ) : (
          <Button variant="primary" type="submit">
            Bekreft booking
          </Button>
        )}
      </Wizard.Actions>
    </Wizard>
  );
}
```

### Data Table Pattern

Standard pattern for data tables with filtering and pagination:

```tsx
function ResourcesTable() {
  const [filters, setFilters] = useState({});
  const [pagination, setPagination] = useState({ page: 1, pageSize: 20 });

  const { data, isLoading } = useResources({ filters, ...pagination });

  return (
    <div>
      {/* Filter bar */}
      <FilterBar>
        <FilterBar.Search
          placeholder="Søk etter navn..."
          onSearch={(query) => setFilters(f => ({ ...f, search: query }))}
        />
        <FilterBar.Select
          label="Status"
          options={statusOptions}
          onChange={(value) => setFilters(f => ({ ...f, status: value }))}
        />
        <FilterBar.DateRange
          label="Periode"
          onChange={(range) => setFilters(f => ({ ...f, ...range }))}
        />
      </FilterBar>

      {/* Active filters */}
      <FilterChips filters={filters} onRemove={(key) => {
        setFilters(f => { const { [key]: _, ...rest } = f; return rest; });
      }} />

      {/* Table */}
      <DataTable
        columns={columns}
        data={data?.items ?? []}
        loading={isLoading}
        emptyState={<EmptyState title="Ingen resultater" />}
      />

      {/* Pagination */}
      <Pagination
        currentPage={pagination.page}
        totalPages={data?.totalPages ?? 1}
        onPageChange={(page) => setPagination(p => ({ ...p, page }))}
      />
    </div>
  );
}
```

### CRUD Operations Pattern

Standard pattern for create, read, update, delete operations:

```tsx
function EntityManager() {
  const [selectedItem, setSelectedItem] = useState(null);
  const [isCreateOpen, setCreateOpen] = useState(false);
  const [isEditOpen, setEditOpen] = useState(false);
  const [isDeleteOpen, setDeleteOpen] = useState(false);

  return (
    <>
      {/* List with actions */}
      <DataTable
        columns={columns}
        data={data}
        actions={(item) => (
          <DropdownMenu>
            <DropdownMenu.Item onClick={() => {
              setSelectedItem(item);
              setEditOpen(true);
            }}>
              Rediger
            </DropdownMenu.Item>
            <DropdownMenu.Item
              variant="danger"
              onClick={() => {
                setSelectedItem(item);
                setDeleteOpen(true);
              }}
            >
              Slett
            </DropdownMenu.Item>
          </DropdownMenu>
        )}
      />

      {/* Create dialog */}
      <Dialog open={isCreateOpen} onClose={() => setCreateOpen(false)}>
        <Dialog.Header>Opprett ny</Dialog.Header>
        <Dialog.Content>
          <EntityForm onSubmit={handleCreate} />
        </Dialog.Content>
      </Dialog>

      {/* Edit dialog */}
      <Dialog open={isEditOpen} onClose={() => setEditOpen(false)}>
        <Dialog.Header>Rediger</Dialog.Header>
        <Dialog.Content>
          <EntityForm item={selectedItem} onSubmit={handleUpdate} />
        </Dialog.Content>
      </Dialog>

      {/* Delete confirmation */}
      <ConfirmDialog
        open={isDeleteOpen}
        onClose={() => setDeleteOpen(false)}
        onConfirm={() => handleDelete(selectedItem)}
        title="Slett element"
        description="Er du sikker på at du vil slette dette elementet?"
        confirmLabel="Slett"
        confirmVariant="danger"
      />
    </>
  );
}
```

### Authentication Flow Pattern

Standard pattern for authentication:

```tsx
function AuthFlow() {
  const { isAuthenticated, user, login, logout } = useAuth();

  if (!isAuthenticated) {
    return (
      <AuthPage>
        <AuthPage.Header>
          <Logo />
          <Heading>Logg inn</Heading>
        </AuthPage.Header>

        <AuthPage.Content>
          {/* BankID login */}
          <Button
            variant="primary"
            onClick={() => login('bankid')}
            icon={<BankIDIcon />}
          >
            Logg inn med BankID
          </Button>

          {/* Demo login (dev only) */}
          {import.meta.env.DEV && (
            <DemoLoginDialog />
          )}
        </AuthPage.Content>
      </AuthPage>
    );
  }

  return <Outlet />;
}
```

### Empty State Pattern

Consistent empty states across the application:

```tsx
// No data
<EmptyState
  icon={<InboxIcon />}
  title="Ingen bookinger ennå"
  description="Når du booker noe, vil det vises her."
  action={
    <Button variant="primary" onClick={handleCreate}>
      Opprett booking
    </Button>
  }
/>

// No search results
<EmptyState
  icon={<SearchIcon />}
  title="Ingen resultater"
  description="Prøv å endre søkekriteriene."
  action={
    <Button variant="secondary" onClick={handleClearFilters}>
      Fjern filtre
    </Button>
  }
/>

// Error state
<EmptyState
  icon={<AlertIcon />}
  title="Noe gikk galt"
  description="Vi kunne ikke laste innholdet."
  action={
    <Button variant="secondary" onClick={handleRetry}>
      Prøv igjen
    </Button>
  }
/>
```

### Navigation Pattern

Standard sidebar navigation:

```tsx
function AppNavigation() {
  const { capabilities } = useAuth();

  const navItems = [
    { label: 'Oversikt', href: '/', icon: <HomeIcon /> },
    { label: 'Bookinger', href: '/bookings', icon: <CalendarIcon /> },
    {
      label: 'Administrasjon',
      icon: <SettingsIcon />,
      items: [
        capabilities.canManageUsers && { label: 'Brukere', href: '/admin/users' },
        capabilities.canManageRoles && { label: 'Roller', href: '/admin/roles' },
      ].filter(Boolean),
    },
  ];

  return (
    <DashboardSidebar>
      <DashboardSidebar.Header>
        <Logo />
      </DashboardSidebar.Header>
      <DashboardSidebar.Nav items={navItems} />
      <DashboardSidebar.Footer>
        <UserMenu />
      </DashboardSidebar.Footer>
    </DashboardSidebar>
  );
}
```
