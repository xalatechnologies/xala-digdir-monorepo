# Card

The Card component groups related content and actions into a contained unit.

<Canvas of={CardStories.Default} />

## Features

- **Content grouping** - Visual container for related items
- **Actions** - Optional action buttons
- **Clickable** - Can act as a link using asChild
- **Flexible** - Supports images, headings, text

## When to Use

Use Card for:
- List items with multiple data points
- Dashboard widgets
- Content previews
- Interactive content blocks

## Accessibility

### Keyboard Navigation
- Tab navigates to interactive elements within card
- Enter activates clickable cards

### Screen Reader Support
- Content structure announced
- Headings provide hierarchy
- Links and buttons announced

## Do and Don't

### Do
- Use consistent card layouts within a page
- Include clear headings
- Keep action count minimal (1-2 per card)
- Use appropriate heading levels

### Don't
- Overload with too much content
- Nest cards within cards
- Use inconsistent card sizes in grids
- Forget focus states for clickable cards

## Thin App Integration

```tsx
import { Card, Heading, Paragraph, Button } from '@xala/ds';

function ListingCard({ listing }) {
  return (
    <Card>
      <Heading level={3} data-size="sm">
        {listing.title}
      </Heading>
      <Paragraph>
        {listing.description}
      </Paragraph>
      <div style={{ display: 'flex', gap: 'var(--ds-spacing-2)' }}>
        <Button variant="secondary" onClick={() => handleDetails(listing.id)}>
          Details
        </Button>
        <Button variant="primary" onClick={() => handleBook(listing.id)}>
          Book Now
        </Button>
      </div>
    </Card>
  );
}
```
