# @xala/ds-registry - Component Documentation

> **Extends:** [Root CLAUDE.md](../../CLAUDE.md)

## Purpose

`@xala/ds-registry` provides documentation and examples for the @xala/ds design system components.

**Package Name:** `@xala/ds-registry`

---

## Content

- Component usage examples
- Design pattern documentation
- Integration guides
- Best practices

---

## Relationship to Storybook

While Storybook (in packages/ds) provides interactive component demos, ds-registry provides:
- Written documentation
- Copy-paste code examples
- Pattern libraries
- Design guidelines

---

## Thin App Strategy

Documentation helps developers:
1. Find existing components in @xala/ds
2. Understand component patterns
3. Avoid creating duplicate components
4. Follow design system guidelines
