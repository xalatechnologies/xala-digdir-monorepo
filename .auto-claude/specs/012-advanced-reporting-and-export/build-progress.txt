EXPORT WORKFLOW:
----------------
User Journey:
1. Click "Eksporter" button → Dialog opens
2. Select format (PDF/Excel/CSV/JSON)
3. Configure date range and filters
4. Click "Eksporter" → Progress dialog appears
5. Real-time progress updates via polling
6. Auto-download when complete
7. Option to re-download or close

Technical Flow:
1. handleOpenExportDialog sets reportType, opens ExportDialog
2. ExportDialog: User configures, clicks export
3. useExportReport().mutate() called with onSuccess callback
4. onSuccess receives data, calls onExportStart(jobId)
5. handleExportComplete sets jobId, opens ExportProgressDialog
6. ExportProgressDialog polls useReportJobStatus(jobId)
7. Shows progress bar, status, estimated completion
8. On complete, auto-downloads via useDownloadReport()
9. handleDownloadComplete closes dialog, resets state
